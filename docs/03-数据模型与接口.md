## 一、表设计（PostgreSQL / Prisma）

### 1.1 用户与认证

| 表 | 关键字段 | 说明 |
|---|---|---|
| `users` | `id` `email`(uniq) `password_hash` `nickname` `avatar_url` `role`(user\|admin) `status`(active\|banned) `email_verified_at` `created_at` | `role` 只区分「普通/管理员」；**是否会员不在 users 上**，由 `memberships` 推导 |
| `sessions` | 用 JWT 则不需要；若要强制下线再加 | 一期省略 |
| `verify_tokens` | `token` `user_id` `kind`(verify_email\|reset_pwd) `expires_at` `used_at` | 邮箱验证 / 找回密码共用 |
| `oauth_accounts` | `provider`(wechat) `open_id` `union_id` `user_id` | 二期微信登录 |

> `role` 与会员等级**分开**：管理员不一定要有会员；会员到期不该动 `role`。

### 1.2 会员与交易

| 表 | 关键字段 | 说明 |
|---|---|---|
| `plans` | `code`(free\|monthly\|yearly\|lifetime) `name` `price_cents` `duration_days`(null=永久) `level`(0\|1) `active` `sort` | 套餐，可由后台改价 |
| `memberships` | `id` `user_id` `plan_id` `status`(active\|expired\|cancelled) `started_at` `expires_at` `source`(redeem\|manual\|wxpay) `order_id` | **同一用户可能有多条历史**；取 `status=active AND expires_at>now()` 判定当前有效 |
| `orders` | `id` `user_id` `plan_id` `amount_cents` `status`(pending\|paid\|refunded\|closed) `pay_method`(redeem\|manual\|wxpay) `trade_no` `created_at` `paid_at` | 二期接微信支付时补 `prepay_id` 等字段 |
| `redeem_codes` | `id` `code`(uniq) `plan_id` `batch` `used_by` `used_at` `expires_at` `created_by` `created_at` | 一期变现主力；批量生成、一次性核销 |

**会员判定 SQL 语义**（写进 `lib/permission.ts`）：
```sql
SELECT 1 FROM memberships
WHERE user_id = $1 AND status = 'active' AND (expires_at IS NULL OR expires_at > now())
LIMIT 1
```

### 1.3 内容

| 表 | 关键字段 | 说明 |
|---|---|---|
| `collections` | `id` `code`(chunk\|scene) `name`(语块英语) `desc` `sort` | 合集 |
| `episodes` | `id` `ep_no`(CK001) `collection_id` `idx`(001) `slug`(get-to) `title` `hook` `cover_title` `cover_sub` `framework_prefix` `framework_suffix` `framework_say` `framework_zh` `framework_note` `quiz_hint` `outro` `duration` `is_free` `published` `sort` `cover_key` `framework_audio_key`(新增) `video_key_douyin` `video_key_bili` `created_at` | 一集一行，**字段与 `content/CK00X.json` 一一对应**，同步脚本直接映射。🔴 `video_key_*` 保留但**恒为 null**（不放视频）；`framework_audio_key` 为服务器 TTS 生成的「听框架」音频 Key（见 [docs/07](07-内容同步与服务器TTS方案.md) §4） |
| `episode_items` | `id` `episode_id` `ord`(1..3) `word` `zh` `audio_en_key` `audio_zh_key` `bg_key` | 3 个例句；`audio_*_key` 由 TTS Worker 生成后回写 |
| `episode_words` | `id` `episode_id` `ord`(0..19) `word` `zh` `audio_key` | 20 词换词表；`audio_key` 由 TTS Worker 生成后回写 |
| `tts_jobs` | `id` `episode_id` `seg_key` `text` `voice` `rate` `text_hash` `object_key` `status` `attempts` `error` | 🔴 **服务器 TTS 任务队列**（每集 24 条），字段与状态机见 [docs/07](07-内容同步与服务器TTS方案.md) §4/§6 |
| `media_assets` | `id` `episode_id` `kind`(audio\|cover\|bg) `bucket` `object_key` `size` `mime` `is_public` | 媒资登记（可选，便于清理孤儿对象）。**`card`/`video` 两种 kind 已废**（网站不放视频、不用卡片图） |

> `episodes.idx` 与 `ep_no` 同源；`is_free` 由后台或同步时的规则（前 N 集）写入，**不在查询时算**（避免规则变更后历史数据错乱）。

### 1.4 学习行为

| 表 | 关键字段 | 说明 |
|---|---|---|
| `progress` | `user_id` `episode_id` `status`(learning\|done) `last_pos` `updated_at` | 唯一键 `(user_id, episode_id)` |
| `favorites` | `user_id` `episode_id` `created_at` | 唯一键同上 |
| `wordbook` | `id` `user_id` `word` `zh` `episode_id` `created_at` | 唯一键 `(user_id, word)` |
| `shadows` | `id` `user_id` `episode_id` `item_ord` `object_key` `duration_ms` `score`(可空) `created_at` | 跟读录音；一期 `score` 留空 |
| `quiz_answers` | `id` `user_id` `episode_id` `item_ord` `answer` `correct` `created_at` | 出题记录，可做错题本 |

## 二、权限模型

```ts
// lib/permission.ts —— 全站唯一判定入口
type Viewer = { id?: string; isAdmin: boolean; isMember: boolean }

type Gate = 'visit' | 'play' | 'audio' | 'download' | 'shadow'

export function canAccess(v: Viewer, ep: Episode, gate: Gate): boolean
```

| gate | 规则 |
|---|---|
| `visit` | 永远 true（标题/封面/框架/3 例句都可看） |
| `play` | `ep.is_free \|\| v.isMember \|\| v.isAdmin` |
| `audio` | 例句音频同上；**换词表 20 词音频需要会员** |
| `download` | 仅会员 / 管理员 |
| `shadow` | 登录即可；免费用户每集 3 次，会员无限（查 `shadows` 计数） |

**调用点必须齐全**（漏一处就是漏洞）：
1. 页面 SSR：`app/chunk/[no]/page.tsx` —— 决定渲染"锁"还是"开"
2. `GET /api/media/sign` —— 签发预签名前的最后一道闸
3. 任何 `admin/*` 接口 —— `assertAdmin()`

## 四、MinIO 对象 Key 规范（唯一真源 `lib/media.ts`）

**Bucket 划分**

| Bucket | 可见性 | 存什么 |
|---|---|---|
| `chunk-public` | 公开读 | **音频（服务器 TTS 生成）**、封面、背景图（**成片不入桶**——网站不放视频） |
| `chunk-private` | 私有 | 会员音源包、用户跟读录音 |

**Key 规则**

```
chunk-public/
  audio/{ep_slug}/00_teach.mp3         # 框架朗读       ← 每集必生成
  audio/{ep_slug}/{NN}_en.mp3          # NN = 01..03 例句英文  ← 每集必生成
  audio/{ep_slug}/{NN}_zh.mp3          # 例句中文              ← 每集必生成
  audio/{ep_slug}/ext_w{NN}.mp3        # NN = 00..19 拓展词逐词 ← 每集必生成（共 24 段）
  cover/{ep_slug}/vertical.png         # 1080×1920（抖音，站内用）
  cover/{ep_slug}/channels.png         # 1080×1260
  cover/{ep_slug}/bilibili.png         # 1146×717
  bg/{ep_slug}/{name}.png              # 例句背景图（来自 assets/chunk/bg/）

  # ⚠️ 以下不再使用（用户 2026-10-09 拍板）：
  #   audio/{ep_slug}/00_hook.mp3   audio/{ep_slug}/98_extend.mp3   audio/{ep_slug}/99_outro.mp3
  #   card/{ep_slug}/*.png          video/{ep_slug}/*.mp4
  # 生成清单与音色规格见 docs/07 第三节

chunk-private/
  pack/{ep_slug}/audio.zip             # 会员整集音频包（按需生成，服务器侧打包）
  shadow/{user_id}/{ep_slug}/{ord}-{ts}.webm
```

`ep_slug` = 小写集号，如 `ck001`（**与视频项目 `assets/chunk/audio/ck001/` 目录名一致，零转换**）。

**访问策略**

| 场景 | 做法 |
|---|---|
| 免费集音频/封面 | 直接 `https://media.chunk.rubyc.cn/chunk-public/audio/ck001/01_en.mp3` |
| 会员集音频 | 后端签发 15 分钟预签名 GET |
| 跟读录音上传 | 后端签发 10 分钟预签名 PUT（限制 `content-type` 与大小） |
| 防盗链 | Nginx 校验 Referer 来源为 `chunk.rubyc.cn`，对 `pack/`（会员音源包）生效；无 `video/` 路径 |

## 五、索引与约束（别忘了）

```sql
-- 唯一的"当前有效会员"查询要快
CREATE INDEX idx_memberships_user_status ON memberships(user_id, status, expires_at);

-- 单集按编号取
CREATE UNIQUE INDEX uniq_episodes_ep_no ON episodes(ep_no);
CREATE UNIQUE INDEX uniq_items_ord ON episode_items(episode_id, ord);
CREATE UNIQUE INDEX uniq_words_ord ON episode_words(episode_id, ord);

-- 词库检索（去重后按词查）
CREATE INDEX idx_words_word ON episode_words(word);

-- 行为表唯一键（防重复）
CREATE UNIQUE INDEX uniq_progress ON progress(user_id, episode_id);
CREATE UNIQUE INDEX uniq_fav ON favorites(user_id, episode_id);
CREATE UNIQUE INDEX uniq_wordbook ON wordbook(user_id, word);

-- 兑换码
CREATE UNIQUE INDEX uniq_redeem_code ON redeem_codes(code);
```
