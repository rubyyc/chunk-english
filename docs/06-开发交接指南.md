## 1. 项目是什么

**苑说英语官网**，域名 **chunk.rubyc.cn**。

- 上游内容源：抖音账号「苑说英语」（rubyc66）的《语块英语》系列短视频——每集教一个英语框架句（如 `How do I get to the ___`），配 3 个例句 + 20 个替换词。
- 本站定位：**视频是钩子，网站是承接**。视频里 30 秒一闪而过的 20 个词，在站上能逐个点着听、跟读、出题默写、收进生词本。
- 商业模式：先涨粉后变现。免费开放核心体验（框架 + 例句 + 出题），会员锁换词表逐词音频 / 下载 / 更高跟读次数。
- 仓库：`git@github.com:rubyyc/chunk-english.git`，本地路径 `~/WorkBuddy/英语短视频/chunk-english/`（嵌在视频生产项目内部，**不是 git 子模块**——视频项目本身不是 git 仓库）。

## 5. 视觉设计系统 v3（暖纸编辑风）

真源 = `static-pages/styles.css` 顶部 `:root`。**改视觉先改这里，页面不写死颜色。**

| 令牌 | 值 | 用途 |
|---|---|---|
| `--accent` | `#E23C20` 朱红 | 点睛色：标题方块、主按钮、强调 |
| `--ink` | `#181613` 暖墨 | 主文字（不用纯黑） |
| `--bg` | `#FBF9F5` 纸白 | 页面底色（暖白，非冷白） |
| `--surface` / `--surface-2` | `#F6F3EC` / `#EFEBE2` | 次级面板 |
| `--line` | `#E7E2D6` | 暖调分割线 |
| `--gold` / `--gold-soft` | `#8A6116` / `#F8EFDC` | 会员标识 |
| `--ok` / `--ok-soft` | `#0E6E52` / `#E2F4EE` | 成功态（绿，**注意与股市红涨绿跌无关**） |

风格特征（v3 新增）：编辑式排版 × 瑞士网格、纸张噪点质感（`body::after`）、区块入场动效（`rise`）、深色页脚、移动端适配。

**组件形态约定**：标题 = 朱红小方块 + 近黑粗体（与视频端 `draw_mark_line()` 同构）；槽位 = 虚线框 + 暖底；徽章 badge-free/badge-vip/badge-soon；表格 `.tbl`；后台 `.adm-*`。

**Logo**：`assets/logo/`。概念 = 气泡（说）+ 白色槽位（留白可填）。`mark.svg` 单图标（favicon 同源）、`logo.svg` 横式带字（页面顶部/页脚用）、`logo-white.svg` 深底反白。使用规范见 `logo.html`。

## 6. 内容数据模型（上游契约）

单集 JSON（`../content/CK001-get-to.json`）关键字段：

```jsonc
{
  "ep": "CK001",
  "framework": "How do I get to the ___",   // 框架句，___ 为槽位
  "items": [ { "en": "...", "zh": "...", "bg": "subway.png" } ×3 ],  // 例句
  "extend": { "words": [ {"en":"gym","zh":"体育馆"} ×20 ] }          // 换词表
}
```

站内音频 Key 即交互语义（由服务器 TTS 按同一命名生成，`audio/ck001/ext_w07.mp3`）：

| segKey | 站内交互 |
|---|---|
| `00_teach.mp3` | 「听框架」按钮 |
| `{01..03}_en/zh.mp3` | 例句跟读（英/中） |
| `ext_w00~19.mp3` | 换词表每行喇叭（**会员锁定项**） |
| ~~`00_hook` / `98_extend` / `99_outro`~~ | ❌ **站内不生成**（视频专用；详见 [docs/07 §3](07-内容同步与服务器TTS方案.md)） |

> 每集 24 段（1 + 6 + 20 − 砍掉的 4 段视频专用音）。音色与语速规格以 docs/07 §3 为唯一真源。

**M0 地基** ✅ **已由另一工具完成**（`03691a7`）：Next.js 15 + Prisma schema（见 docs/03）+ MinIO client + Tailwind 令牌。

部署（已拍板）：`git clone` 到服务器 `/opt/apps/` → 1Panel 数据库面板建 `chunk_english` 库（用**自带 PG**）→ `docker compose up -d --build` → 1Panel 网站建反向代理 `chunk.rubyc.cn → 127.0.0.1:3000` → DNS 解析 → SSL。app 与自带 PG / 应用商店 MinIO 同在 `1panel-network`，容器名直连。全流程见 `docs/04`。

⚠️ 已知部署坑（详见 docs/04 坑表）：MinIO 9000/9001 只绑 127.0.0.1 不放公网；预签名 URL 的 host 必须换成 `S3_PUBLIC_BASE`（否则签出来是 `http://minio:9000` 浏览器连不上）。
