# 05 · 内容同步方案（视频项目 → 网站 / MinIO）

> ⚠️ **本文档已废弃（2026-10-10 被 [docs/07](07-内容同步与服务器TTS方案.md) 取代）**
> 用户拍板改为：**本地一键只同步内容数据 + 封面 + 背景图；音频由服务器 TTS Worker 生成（本地不生成不上传 mp3）；网站不放视频**。
> 留档原因：第一节「数据来源映射表」与对象 Key 规范（`audio/{ep_lower}/{segKey}.mp3`）**仍然有效**，docs/07 直接引用。

> 核心问题：视频做完了，怎么让网站上出现这一集？
> 答案：**一个命令**，读 `content/*.json` + `assets/` + `产物/`，推音频上 MinIO，写单集数据进数据库。

## 一、数据来源映射

| 网站字段 | 来源 | 转换 |
|---|---|---|
| `episode.ep_no` | `content.episode` | `"CK001"` |
| `episode.collection` | `content.collection` | → `collections.code` |
| `episode.idx` / `slug` | `content.index` / 文件名 | `001` / `get-to` |
| `episode.hook` | `content.hook` | — |
| `episode.cover_title/sub` | `content.cover.title/sub` | — |
| `episode.framework_*` | `content.framework.{prefix,suffix,say,zh,note}` | 拆 5 列 |
| `episode.quiz_hint` / `outro` | `content.quiz_hint` / `outro` | — |
| `episode_words[]` | `content.extend.words[20]` | `ord` = 数组下标 0–19 |
| `episode_items[]` | `content.items[3]` | `ord` = 1–3 |
| 例句音频 Key | `assets/chunk/audio/{ep_lower}/{NN}_en.mp3` | → `audio/{ep}/{NN}_en.mp3` |
| 逐词音频 Key | `assets/chunk/audio/{ep_lower}/ext_w{NN}.mp3` | → `audio/{ep}/ext_w{NN}.mp3` |
| 封面 Key | `产物/语块英语/<dir>/{抖音,视频号,B站}/cover.png` | → `cover/{ep}/{vertical,channels,bilibili}.png` |
| 成片 Key | 同上的 `video.mp4` | → `video/{ep}/{douyin,bilibili}.mp4` |
| `duration` | `产物/.../manifest.json` 的 `duration` | — |
| `is_free` | 规则：`idx <= FREE_EPISODE_LIMIT` | 可 `--free` 覆盖 |

> `ep_lower` 取 `ep_no.lower()`（`CK001` → `ck001`），**与视频项目 `assets/chunk/audio/ck001/` 目录名天然一致，无需改名**。

## 二、导入脚本设计

**位置**：`chunk-english/scripts/import_episode.py`
**理由**：它属于网站侧的数据入口，放网站仓库里，网站可以独立部署与自检；通过 `--video-root` 指向视频项目即可。

```
chunk-english/scripts/import_episode.py

用法：
  python3 scripts/import_episode.py --ep CK001 --video-root ../../ \
      --upload --db            # 上传 MinIO + 写数据库
  python3 scripts/import_episode.py --ep CK001 --dry-run     # 只打印计划，不落地
  python3 scripts/import_episode.py --all --upload --db
```

**执行流程**

```
 1. 读内容        content/CK001-get-to.json          （结构数据）
 2. 读清单        产物/语块英语/CK001-get-to/manifest.json（时长、平台成片）
 3. 校验资产      assets/chunk/audio/ck001/ 下 00_hook…ext_w19 是否齐全
                  → 缺 01_en.mp3 这类关键文件直接报错退出（不静默跳过）
 4. 上传 MinIO    按 docs/03 的 Key 规范 PUT 到 chunk-public（已存在则跳过，比对 ETag）
 5. 写数据库      upsert episodes / 重建 episode_items + episode_words（幂等）
 6. 打印结果      新增/更新/跳过/失败 计数 + 后台可访问 URL
```

**幂等原则**：`--ep` 重复执行结果一致。`episode_items` / `episode_words` 用「先删后插」；
`episodes` 用 `ep_no` upsert（**不覆盖后台手工改过的 `is_free` 与 `published`**，除非显式 `--force-meta`）。

**参数**

| 参数 | 说明 |
|---|---|
| `--ep CK001` | 单集；`--all` 全量 |
| `--video-root` | 视频项目根目录（默认从环境变量 `VIDEO_ROOT` 读） |
| `--upload` | 上传媒资到 MinIO（不加则只写库，Key 按规范预生成） |
| `--db` | 写数据库（不加则只上传媒资） |
| `--dry-run` | 全流程演练，只输出计划 |
| `--free` / `--paid` | 强制设定免费/会员集 |
| `--force-meta` | 覆盖后台已编辑的展示字段 |

**依赖**：`boto3`（S3）、`psycopg2-binary` 或 `SQLAlchemy`（若网站侧用 Prisma，脚本可用 `psycopg2` 直连，避免引入 Node 环境）。

## 三、两种接法（选一）

| 方案 | 做法 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| **① 脚本直连（推荐一期）** | `import_episode.py` 直接连生产 PG + MinIO 上传 | 简单、可控、能 `--dry-run` | 需要本机能访问生产库（或脚本在服务器上跑） | 现在就够用 |
| **② 后台 API 导入** | 脚本调 `/api/admin/episodes/import`，服务端落库 | 不暴露 DB；有审计 | 需先开发接口、传大文件要分片 | 二期做后台「重新导入」按钮时 |

> 一期先用 ①，同时把接口留出来（`POST /api/admin/episodes/import` 内部逻辑与脚本共用同一份映射表）。

### 在服务器上跑（无需本地连生产库）

```bash
ssh root@<服务器IP>
docker compose exec app python3 scripts/import_episode.py \
  --ep CK001 --video-root /data/video-workspace --upload --db
```
> 需把视频项目的 `content/`、`assets/`、`产物/` 目录挂载或同步到服务器（只读挂载即可，**不需要视频工程代码**）。

## 四、日常发布流程（与视频流程串起来）

```
① 本地做视频        python3 scripts/build_chunk.py content/CK002-xxx.json
② 审图确认
③ 打包产物          python3 AI发布视频流程/pack_release.py CK002
④ 三端发布          python3 AI发布视频流程/publish.py post --episode CK002 --go
⑤ 🔴 上网站         python3 chunk-english/scripts/import_episode.py --ep CK002 --upload --db
                    （或后台点「重新导入」）
⑥ 验收              打开 https://chunk.rubyc.cn/chunk/ck002 逐段点一遍
```

**建议**：把 ⑤ 并进 `pack_release.py` 的一个可选步骤（`--site`），这样发布视频时顺手就把网站更了，不会漏。

## 五、与视频项目的关系（边界）

| 项 | 视频项目（英语短视频） | 网站项目（chunk-english） |
|---|---|---|
| 内容 JSON | **真源**，在 `content/` | 只读导入，快照存 `source.json` |
| 音频/来源素材 | **真源**，在 `assets/` | 上传后 MinIO 是运行时真源 |
| 成片/封面 | **真源**，在 `产物/` | 上传后 MinIO 是运行时真源 |
| 单集展示字段 | 可被后台覆盖（如标题措辞） | 覆盖值只存在网站库，**不回写视频项目** |
| 免费/会员标记 | 不关心 | 网站独有 |

> **单向数据流**：视频项目 → 网站。网站的任何编辑不回灌视频项目，避免两个真源打架。
> 需要改内容时，改 `content/*.json` 重新导入（用 `--force-meta`），或在后台改并在文档里记一笔。
