# 02 · 功能模块与页面结构

---

## 一、七大功能模块

| # | 模块 | 职责 | 关键内容 | 依赖 | 优先级 |
|---|---|---|---|---|---|
| M1 | **内容域** | 承载单集结构数据 | 合集 / 单集 / 语块框架 / 例句 / 拓展词 / 媒资引用 | — | P0 |
| M2 | **用户域** | 身份与会话 | 注册、登录、邮箱验证、找回密码、微信 OAuth（二期） | — | P0 |
| M3 | **会员域** | 等级与订阅 | 套餐、会员状态、有效期、兑换码、订单（二期微信支付） | M2 | P0 |
| M4 | **权限域** | 决定"看得到什么" | 免费集边界、会员全量、音频下载权、跟读次数、内容可见性开关 | M2 M3 | P0 |
| M5 | **学习域** | 产生留存 | 学习进度、收藏、生词本、跟读录音与回放 | M2 | P1 |
| M6 | **媒体域** | 音视频分发 | MinIO 对象、预签名 URL、直传、防盗链、封面派生 | — | P0 |
| M7 | **后台域** | 运营与变现 | 内容导入/编辑、用户与会员、订单与兑换码、数据看板 | 全部 | P1 |

### 各模块细化

**M1 内容域**

- 合集：《语块英语》（唯一在做）；预留《场景英语》。
- 单集字段映射自 `content/CK00X.json`：`framework{prefix,suffix,say,zh,note}`、`items[3]{word,zh,bg}`、`extend.words[20]{word,zh}`、`quiz_hint`、`outro`、`hook`、`cover{title,sub}`。
- 派生字段：`free`（是否免费集）、`published`（是否上线）、`sort`（按 index 排序）、`duration`、`cover_url`。

**M4 权限域（最容易被做烂，单列）**

| 权益 | 游客 | 免费用户 | 会员 | 管理员 |
|---|---|---|---|---|
| 浏览首页/合集列表/单集标题 | ✅ | ✅ | ✅ | ✅ |
| 播放免费集（前 5 集）完整内容 | ✅ | ✅ | ✅ | ✅ |
| 会员集：仅看标题 + 视频预览 | ❌ | ❌ | ✅ | ✅ |
| 会员集：音频逐词发音 / 跟读 | ❌ | ❌ | ✅ | ✅ |
| 音频批量下载 | ❌ | ❌ | ✅ | ✅ |
| 跟读录音留存与回放 | ❌ | 3 次/集 | 无限 | 无限 |
| 生词本 / 收藏 / 进度 | ❌ | ✅ | ✅ | ✅ |
| 后台入口 | ❌ | ❌ | ❌ | ✅ |

判定必须是**服务端**：页面 SSR 时调 `canAccess(user, episode)`，API 层再校验一次（不信任前端）。

**M6 媒体域**

| 类型 | 存储策略 | 访问方式 |
|---|---|---|
| 音频（例句/逐词） | `chunk-public` bucket | 公开读（免费集）；会员集由后端签发预签名 |
| 封面 / 卡片图 | `chunk-public` bucket | 公开读 |
| 成片 mp4 | `chunk-public` bucket（一期） | 公开读 + Nginx 限速防盗链 |
| 跟读录音 | `chunk-private` bucket | 仅预签名 PUT/GET，私有 |
| 会员音源包 | `chunk-private` bucket | 预签名，5–15 分钟有效 |

## 二、站点地图

```
【公开区】
/                            首页 —— 今日一集 + 最新集 + 合集入口 + 会员引导
/chunk                       语块英语合集列表（编号卡片墙，含免费/会员角标）
/chunk/[no]  ⭐              单集学习页（核心）
/words                       词库检索（跨全集搜词，先只搜已上线集）
/pricing                     会员定价（套餐对比表 + FAQ）
/about                       关于（账号介绍，三端引流）
/login  /register  /reset    登录 / 注册 / 找回密码

【会员区（需登录）】
/me                          我的学习（继续学习、进度环、最近跟读）
/me/membership               会员与账单（当前等级、到期日、兑换码入口、订单）
/me/wordbook                 生词本
/me/favorites                我的收藏
/me/shadows                  跟读记录（回放 + 对比原音）

【管理区（需 admin）】
/admin                       数据看板（用户数 / 会员数 / 播放 / 转化）
/admin/episodes              单集管理（列表、上下架、免费标记、重新导入）
/admin/users                 用户与会员（搜索、改等级、赠会员、封禁）
/admin/orders                订单与兑换码（生成码、查看核销）
```

## 三、核心页面：单集学习页 `/chunk/[no]`

这是整个站的价值所在——**把视频里一闪而过的六类卡片变成六段可交互学习区**，顺序与成片一致。

```
┌──────────────────────────────────────────────────────────────┐
│  ‹ 返回合集    语块英语 · 第 001 期                  [收藏 ♡]  │
├──────────────────────────────────────────────────────────────┤
│  ① 封面区（hook）                                            │
│     大标题「问路，这一句就够」                                │
│     副标题「换掉地点，句子照样能用」                          │
│     ▶ 播放视频（竖屏 9:16，默认折叠，点开展开）               │
├──────────────────────────────────────────────────────────────┤
│  ② 框架区（教框架）                                           │
│     How do I get to the ______ ?                              │
│     我怎么去[地点]？            🔊听框架(00_teach.mp3)        │
│     注释：换掉地点，句子照样能用                              │
├──────────────────────────────────────────────────────────────┤
│  ③ 例句区 × 3（本集替换）                                     │
│   ┌────────────┬────────────┬────────────┐                   │
│   │ subway     │ hospital   │ school     │  ← 切 tab 或全部列 │
│   │ 地铁站      │ 医院        │ 学校        │                   │
│   │ 🔊EN 🔊ZH   │ 🔊EN 🔊ZH   │ 🔊EN 🔊ZH   │                   │
│   │ ◉ 按住跟读  │ ◉ 按住跟读  │ ◉ 按住跟读  │                   │
│   └────────────┴────────────┴────────────┘                   │
├──────────────────────────────────────────────────────────────┤
│  ④ 出题区（quiz_hint：先自己说一遍）                          │
│     只给中文 → 输入英文 → 判分 → 显示答案+朗读                 │
│     「地铁站」→ How do I get to the subway?                   │
├──────────────────────────────────────────────────────────────┤
│  ⑤ 收尾区（outro）：「框架记住，地点随便换」                   │
├──────────────────────────────────────────────────────────────┤
│  ⑥ 换词表（20 词 × 2 列）                                     │
│     引导语(98_extend.mp3) · 提示「截图存下来，见到就能用」     │
│     gym 体育馆 🔊      school 学校 🔊                         │
│     museum 博物馆 🔊   hotel 酒店 🔊                          │
│     …（每行独立喇叭 → ext_w00.mp3 … ext_w19.mp3）             │
│     ✓ 加入生词本                                              │
├──────────────────────────────────────────────────────────────┤
│  ⑦ 学习动作条（吸底）                                         │
│     [上一集]  [标记已学]  [下一集]     进度 3/5 集            │
└──────────────────────────────────────────────────────────────┘
```

**会员拦截形态**（会员集，非会员访问）：
- ② ③ 正常可见（框架与 3 个例句是引流内容，不锁）
- ⑥ 换词表 20 词**显示词条但音频锁住** + 半透明遮罩「解锁领会员」
- ⑦ 条上方插一条会员 CTA
- 视频④出题区完整可用（引导体验后转化）

> 设计取舍：**锁"扩展深度"不锁"核心体验"**。用户要能尝到甜，才愿意付。

## 四、其他关键页面

| 页面 | 关键模块 | 说明 |
|---|---|---|

## 五、视觉规范（与视频端共用一套）

| 项 | 值 | 来源 |
|---|---|---|
| 主色（强调） | 朱红 `#E23C20` | 与视频 `C_ACCENT=(226,60,32)` 一致 |
| 主文本 | 近黑 `#1A1A1A` | 与视频一致 |
| 底 | 白 `#FFFFFF` / 浅灰 `#F7F7F8` | 浅色系（用户明确偏好） |
| 字体 | 中文 · 思源黑体 / 系统黑体；英文 · Inter | 与视频端 Helvetica Neue 同族观感 |
| 圆角 / 描边 | 卡片 12px；强调元素白描边 2px | 呼应视频"深色字+白描边压图" |
| 禁忌 | 深色大面积面板、磨砂玻璃整卡 | 沿用视频端「不遮挡背景图」时定下的浅色路线 |

> 记忆点复刻：视频里的**朱红小方块 + 近黑粗体**标题形态，在网站导航与区块标题上沿用，让用户一眼认出是同一品牌。
